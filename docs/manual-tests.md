# Manual tests of version 1

This list has the manual tests of prompts 00 to 10. The order is the order that a person does them on a fresh computer. Duplicates are merged into one row. The column "From" gives the prompt and the number of the test in its "Manual tests" section.

"Spec trace" marks a test that prompt 10 added. The spec trace (`docs/spec-trace.md`) found a rule that no automated test can prove and that no prompt tests by hand.

Fill in the "Result" column: "Pass", or what went wrong.

Cmd is the Command key on macOS. On Windows and Linux, use Ctrl in place of Cmd.
