# Spec trace of version 1

This table connects each rule of `docs/spec/PRODUCT.md` to the code that does it and to the test that proves it. Prompt 10 made it.

How to read the columns:

- Code: a file in `src/`. When it helps, the cell also names a function or a class.
- Test: "Unit" is a Vitest file in `test/unit/`. "E2E" is a Playwright file in `test/e2e/`, with the name of the test in quotes. "Manual" is a row of `docs/manual-tests.md`.
- `release.test.ts` and `release.spec.ts` are the tests that prompt 10 added for rules that had no automated test.

Two rules belong to optional later prompts and have no code in version 1: signed installers with auto-update (prompt 11), and Touch ID passkeys on macOS (prompt 12). Prompt 10 puts them out of scope.

## Find in page

The companion spec adds Find after the read-only snapshot in this repository.
`src/main/find-in-page.ts` owns the search and its lifetime. `src/renderer/src/FindScreen.tsx` draws the bar.
`src/main/shortcuts.ts` and `src/main/app-menu.ts` expose Cmd+F and Ctrl+F.
`test/e2e/find.spec.ts` tests page search, counts, navigation between matches, focus, account changes, Calendar, child windows, and sender restrictions.
`test/unit/shortcuts.test.ts` tests the shortcut table on all three platforms. The real Google tests are in `docs/manual-tests.md`.
