# Shifted

Shifted is a desktop app that keeps several Google accounts in one window, each with Gmail and Google Calendar. This glossary gives each word in the documents one meaning.

## Language

**Shifted**:
The desktop app that these documents describe.
_Avoid_: the app (when "app" alone can also mean a Google app)

**Account**:
One Google account that a person added to Shifted.
_Avoid_: profile, mailbox, inbox, user, workspace

**Session**:
The private store of cookies and site data that belongs to one account.
_Avoid_: profile, partition, container, data store

**Google app**:
Gmail or Google Calendar, as shown inside one account.
_Avoid_: app, service, view, tab

**Sidebar**:
The vertical strip on the left side of the window that lists the accounts.
_Avoid_: dock, rail, toolbar, account switcher

**Tab bar**:
The thin bar above the content area, with one tab for each Google app of the selected account.
_Avoid_: toolbar, header, app switcher

**Content area**:
The rounded card below the tab bar, which shows one Google app of one account.
_Avoid_: main view, web view, pane

**Backdrop**:
The background of a Shifted window around the content area. In the main window, it has a tint of the color of the selected account.
_Avoid_: chrome, frame, window background

**Selection tile**:
The shape behind the selected account in the sidebar. It joins the content area.
_Avoid_: highlight, account tab, selection box

**Selected account**:
The account whose Google app the content area shows now.
_Avoid_: active account, current account

**Child window**:
A separate Shifted window that shows a Gmail pop-out for one account, with the session of that account.
_Avoid_: popup, new tab, secondary window

**Unread count**:
The number that Gmail shows next to Inbox for one account.
_Avoid_: unread total, mail count, badge number

**App badge**:
The sum of the unread counts of all accounts, shown on the app icon of Shifted.
_Avoid_: dock badge, taskbar badge, total badge

**Asleep**:
The state of a Google app that Shifted unloaded to save memory. If you open it, Shifted loads it again.
_Avoid_: hibernated, suspended, discarded, closed

**Sign-in window**:
A small separate Shifted window that shows Google's sign-in page for one account, with the session of that account.
_Avoid_: login window, auth popup, sign-in dialog

**Account picker**:
The small Shifted window that asks which account to use for a `mailto:` link from another app.
_Avoid_: chooser, selector, mailbox dialog

**Configuration**:
The values that a person can change in Shifted, for example quiet hours or the color of an account.
_Avoid_: settings, preferences, options

**Configuration window**:
The Shifted window where you change the configuration. Its title on screen is `Settings`, to match the operating systems.
_Avoid_: settings window, preferences window

**Default browser**:
The web browser that the operating system opens for web links, for example Chrome, Safari, Edge, or Firefox.
_Avoid_: external browser, system browser
